## Why

目前材料只能下载后查看，教师无法在课堂上直接展示讲义内容；已上传的 txt/md 文本材料中的知识无法被检索利用，学生只能凭文件名逐个下载查找。本次变更新增文本材料在线预览，并基于 txt/md 材料构建按班级隔离的语义知识库，让师生能用自然语言在本班材料中检索答案且可溯源到原文件。

## What Changes

- 教师上传表单新增 **txt、md** 两种允许格式，并在上传界面明确展示服务端配置的完整允许格式清单及其中支持在线预览的格式（其余格式仍可上传下载但不提供预览，难以支持的格式不纳入）。
- 新增**材料在线预览**：本班教师与学生均可在浏览器内预览 txt（纯文本等宽展示）与 md（渲染为 HTML）材料；渲染在服务端完成并对原始 HTML/脚本做无害化处理，预览接口复用现有班级数据边界（跨班 404）。
- 新增**班级知识库**：txt/md 材料上传成功后自动分块、本地嵌入并写入向量索引；索引带班级标识，与材料同生命周期持久化；提供幂等的 `flask reindex-kb` 重建命令用于回填与失败修复。
- 新增**知识库检索页**：本班师生按自然语言检索本班 txt/md 材料内容，服务端以会话用户的班级强制过滤；结果按相关度排序，提供命中文片段、来源材料名与跳转链接（可溯源到原文件/预览页），任何情况下不泄露其他班级内容。
- 嵌入计算使用**随镜像分发的本地中文嵌入模型**（ONNX 运行时，无需 torch、无需外部 API 或密钥，材料文本不出服务器/容器网络）；向量存储使用 sqlite-vec，与现有 SQLite 数据库同处 `/data` 持久卷。
- 种子数据新增中英文文本示例材料（A/B 班各有不同内容），使检索与跨班隔离在 `docker compose up` 后即可演示。

## Capabilities

### New Capabilities

- `knowledge-base`: 基于 txt/md 教学材料、按班级隔离的向量知识库——自动分块与本地嵌入、班级强制范围的语义检索、命中结果内容溯源、索引持久化与幂等重建。

### Modified Capabilities

- `teaching-materials`: 允许格式清单扩展 txt/md；新增上传界面展示支持格式的要求；新增 txt/md 材料的班级内在线预览要求（md 安全渲染）。
- `app-foundations`: 预置演示数据要求扩展为包含可供知识库检索演示的文本材料（A/B 班内容不同，可直接演示跨班检索隔离）。

## Impact

- **新增依赖**：`Markdown` + `bleach`（md 渲染与 HTML 消毒）、`fastembed`（ONNX 本地中文嵌入，间接引入 onnxruntime/numpy/tokenizers）、`sqlite-vec`（SQLite 向量扩展）。
- **Docker**：构建期预下载约 100MB 的 BGE-small-zh 模型到镜像内（支持通过构建参数配置 HF 镜像源）；镜像体积预计增加约 300–500MB；向量索引随现有 `/data` 命名卷持久化。宿主机的 Docker 虚拟磁盘需位于有足够空间的分区（部署文档提示迁移 disk image location）。
- **代码**：新增 `app/kb/` 包（分块、嵌入、索引、检索、Blueprint 与模板）；`materials` 模块新增预览路由/模板；`models.py` 增加 `Material.indexed_at` 与知识库分块表；`config.py`/`.env.example` 新增知识库相关配置；`cli.py` 新增 `reindex-kb`；`seed.py` 增加文本示例材料。
- **接口/页面**：新增 `GET /materials/<id>/preview`、`GET /kb`（检索页，表单 GET 提交）；材料列表页与导航栏相应更新；不改动现有鉴权与上传/下载 HTTP 语义。
- **测试**：嵌入层提供确定性 stub 后端，测试无需下载模型；新增预览安全与知识库隔离/溯源测试，既有测试保持通过。
