## Purpose

把本班 txt/md 教学材料转化为按班级强制隔离的可检索知识库：材料上传后自动分块并在服务端本地嵌入向量化，本班师生可用自然语言检索本班材料内容，命中结果可溯源到来源材料；索引持久化保存并可通过命令幂等重建。

## ADDED Requirements

### Requirement: 文本材料自动入库为知识片段

系统 MUST 在 txt/md 材料上传成功后，自动提取其文本内容、切分为带顺序编号与原文位置信息的片段，并计算嵌入写入该班知识库；仅扩展名为 txt 与 md 的材料进入知识库，其他允许类型的材料 MUST NOT 产生任何知识库片段。每个片段 MUST 携带其所属班级标识与来源材料标识，且班级标识 MUST 只取自会话用户，不接受请求中自报的班级。

#### Scenario: 上传文本材料后无需额外操作即可被检索

- **WHEN** 教师成功上传一个包含可识别文本内容的 txt 或 md 材料后，本班用户立即检索其中的内容
- **THEN** 系统返回来源于该材料的命中片段，无需人工执行索引命令

#### Scenario: 非文本材料不进入知识库

- **WHEN** 教师上传 pdf、docx、图片等非 txt/md 类型的允许材料
- **THEN** 系统不为其创建任何知识库片段，该材料内容不出现在任何检索结果中

#### Scenario: 片段强制归属上传者所在班级

- **WHEN** 教师上传文本材料（即使请求中附带伪造的班级字段）
- **THEN** 产生的全部片段的班级标识与该教师会话所属班级一致

#### Scenario: 入库失败不破坏材料上传结果

- **WHEN** 材料已保存且元数据已入库，但片段切分、嵌入或写索引过程失败
- **THEN** 本次材料上传的结果仍然成立（文件与材料记录保留），系统记录失败日志并使该材料可被重建命令重新索引，且不产生只写入一半的片段集合

### Requirement: 知识库检索强制限定本班范围

系统 MUST 为已登录的教师与学生提供知识库语义检索；检索执行 MUST 以会话用户所属班级作为强制过滤条件，任何来自查询参数或表单的班级标识都 MUST NOT 能扩大检索范围。未登录用户访问检索页面 MUST 被重定向到登录页，未登录的程序化检索请求 MUST 返回 401。系统 MUST 对空查询与超长查询给出明确的输入提示而不执行检索。

#### Scenario: 本班用户检索命中本班材料

- **WHEN** 已登录用户用自然语言检索与其本班某份文本材料语义相符的内容
- **THEN** 系统返回按相关度排序的命中片段，且全部片段属于该用户所在班级

#### Scenario: 跨班内容在任何情况下都不泄露

- **WHEN** B 班材料中存在与查询完全相同或高度相符的内容，A 班用户执行同一查询
- **THEN** 返回结果中不包含任何 B 班片段、文件名或原文文本，如同 B 班数据不存在

#### Scenario: 学生与教师检索权限一致且仅及本班

- **WHEN** 同班的学生与教师分别执行相同检索
- **THEN** 两者都能检索本班知识库且可见范围相同；学生不因其角色被排除在检索之外

#### Scenario: 未登录检索被拒绝

- **WHEN** 未登录用户打开检索页或直接调用检索接口
- **THEN** 页面请求 302 重定向到登录页（登录后可回跳），程序化请求返回 401，不返回任何片段内容

#### Scenario: 非法查询输入被拒绝

- **WHEN** 提交空查询、纯空白查询或超过系统规定长度上限的查询
- **THEN** 系统不执行检索并返回明确的输入提示（页面错误提示或 400 级响应）

### Requirement: 检索结果可溯源到来源材料

每条检索结果 MUST 展示来源材料的原始文件名、命中片段的文本内容（片段或高亮摘要）以及该片段在原文中的位置或所属小节提示，并 MUST 提供指向该材料详情页或预览页的链接；溯源链接本身 MUST 经过相同的班级鉴权，跨班访问仍为 404。

#### Scenario: 结果包含来源与片段内容

- **WHEN** 检索产生命中结果
- **THEN** 每条结果至少展示来源文件名、命中片段文本与相关度信息，用户可判断答案出处

#### Scenario: 溯源链接可回到原文对应位置

- **WHEN** 用户点击某条结果的来源链接
- **THEN** 系统打开该材料的详情或预览页，并能定位（如锚点或位置标记）到该片段在原文中的大致位置

#### Scenario: 结果按相关度排序且数量受限

- **WHEN** 检索存在多个命中
- **THEN** 结果按与查询的相关度从高到低排列，且一次返回数量不超过系统规定的上限

### Requirement: 嵌入计算在服务端本地完成

系统 MUST 使用随部署产物分发的本地嵌入模型，在服务端完成查询与材料片段的向量化；材料文本与用户查询 MUST NOT 被发送到任何外部网络服务，且在未配置任何第三方嵌入 API 密钥的情况下，入库与检索 MUST 可完整工作。

#### Scenario: 无外网访问时检索可用

- **WHEN** 应用在除宿主机访问外无外部网络的环境中运行，教师上传文本材料后用户执行检索
- **THEN** 入库与检索均正常完成，全过程不发起对外部嵌入服务的网络请求

#### Scenario: 无需配置第三方密钥

- **WHEN** 部署时只配置应用既有的必要环境变量（如会话密钥），未配置任何嵌入服务密钥
- **THEN** 知识库入库与检索功能立即可用，应用不因缺少嵌入 API 密钥而报错

### Requirement: 向量索引持久化与幂等重建

知识片段、嵌入向量与索引 MUST 持久化在服务端受管存储中并随应用数据卷保留，容器或进程重启、重建后已入库材料 MUST 仍可被检索。系统 MUST 提供可重复执行的知识库重建命令：对文本材料（可限定为全部或尚未成功索引的范围）重新切分、嵌入并写入索引；同一材料重复重建 MUST NOT 产生重复片段。

#### Scenario: 容器重建后索引仍可用

- **WHEN** 文本材料上传入库后停止并删除应用容器，再重新启动
- **THEN** 无需重新上传即可检索到该材料的片段内容

#### Scenario: 重建命令幂等

- **WHEN** 对同一批材料连续执行两次知识库重建命令
- **THEN** 第二次执行后每个材料的片段数量与内容和第一次一致，不产生重复片段或重复命中

#### Scenario: 历史缺失索引可被回填

- **WHEN** 数据库中存在上传于旧版本、或此前索引失败的 txt/md 材料而知识库中缺少其片段
- **THEN** 执行重建命令后这些材料被完整索引并可被本班检索命中
